# C8: AMM fills move the price with size

Mode: C (contracts) · Writer: top agent · Depends on: none · PLAN row: C8

## Current behavior
Observed: `mind/fill.ts:27-39` filled AMM buys and sells at the last price minus the fee, and `quoteFor` gave AMM impact 0, so any size cost the same.

## Required behavior
- `trade.*` carries `pool_sol`: the pool's SOL reserve, from NATS `quoteReserves` on a `pump_amm` trade (recorded real slice `tests/e2e/fixtures/pump/trades-slice.json`: 63 AMM trades, all with it); null on the curve and in the RPC backfill.
- AMM fills model a constant-product pool: SOL reserve x, token reserve x / price. Buys and sells move the price with size; `quoteFor` gives impact ((x + net) / x)^2 - 1.
- With no known reserve an AMM buy quotes infinite impact, so the spec and the gate refuse it. An exit still runs, at the last price minus fees.
- The desk carries the last known reserve over trades without one; the live gate reads it from the Tape.

## Invariants
The model was checked against eight real AMM trades: predicted over real tokens or SOL within 1-4% (fees ignored in that check), 9% on one small sell.
