- Observed: case files are built from the Tape and the Board only (`services/core/src/hunt/case.ts:1-2`); the OBSERVED block shows `quoted_callout_id` (`case.ts:194`, `:219`) but no copy. The caller ledger reads `quoted_callout_id` and `via` only (`services/core/src/scorekeeper/ledger.ts:68`).

- Observed: no narrative clustering exists. Narratives come only from the Jev `narrative` choice per callout (`services/core/src/reflex/reflex.ts:46`) and BettaFish's `synthesis.feed` claims (`services/core/src/mcp/toolbox.ts:285-295`).
- Observed: rug reports are recalled only inside the Wiki writer (`graphs.ts:208`); the rug feed (`services/relay/src/rug-feed.ts`) and the `exit` pack do not use similarity. No site or slow-engine search over wiki pages or reports.

## Required behavior
1. Copy on the Tape. When the Librarian stores a callout with `copy_of`, it emits one `callout.copy` event `{ callout_id, copy_of, similarity, model, method }` (subject = `callout_id`, dedupe `callout.copy:<callout_id>:<model>`). `seen_time` is the copy's `seen_at`, never wall clock, so the event sorts where a replay expects it.
2. Case file. `buildCase` reads `callout.copy` for the callout and shows "Copy of" (earlier callout id, similarity, model) in OBSERVED, in the AI JUDGMENTS class since it is a model output. No copy → the field is `null`. The file still rebuilds byte-identical.
3. Caller ledger. Each row counts `copies` (callouts of that caller that are copies). Denominators unchanged.
4. Narrative clusters. A pure function `clusterNarratives(rows, as_of)` groups callout memory rows seen at or before `as_of` by greedy single-link on cosine ≥ `NARRATIVE_SIMILARITY` (config, default 0.85), visiting rows in `(seen_at, id)` order; cluster id = id of its first row. Same rows → same clusters, same ids. The Librarian emits `narrative.clusters` once per hour slot (as_of = slot start). The `coin` pack prompt and the BettaFish bridge input get the coin's cluster size and the cluster's earliest callout text.
5. Failure cases: no embedder or budget refused → no `callout.copy`, no clusters event, cursor not advanced (E5 rule kept); a model change never links vectors across models.

## Invariants
Tape append-only. Replay determinism: `callout.copy` and `narrative.clusters` depend only on rows seen at or before their `seen_time`. Risk Gate authority untouched (clusters are context, not a trade input). No new dependency. Model, URL and provider stay out of code.
