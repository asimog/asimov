# D3: Every MCP write passes one public-text check, and a borrowed citation id is dropped

Mode: C (the MCP write door) · Writer: top agent · Depends on: D1 (both touch contracts) · PLAN row: D3

## Current behavior
- observed: only `emit_forum_line` and swarm posts run `checkProse` (`services/core/src/mcp/toolbox.ts:271`, `:288`). The text fields of `emit_synthesis_feed` (`narratives[].summary`, `coin_stances[].why`, `suspicious[].text`) and `emit_synthesis_coin` (`narrative`, `claims[].text`) reach the Tape and the site unchecked (`toolbox.ts:234-266`).
- observed: `citedCallouts` checks only that the id exists and was seen by now (`toolbox.ts:83-87`). It never checks that the callout is inside the run's window. A real id from last week, a "borrowed id", passes.
- observed: the BettaFish worker strips citation markers from the text with a regex (`CID.sub`, `services/bettafish/engine/asimog_worker.py:181`) and takes cites from the same text; check that the markers are a separate field end to end.

## Required behavior
1. **One check.** A single `publicText(text, max)` in core (wrapping the existing `checkProse` and the `clean` from `reflex/guard.ts`) runs on every text field of every MCP write tool. A refused field drops that claim (feed and coin), or refuses the call (forum line, report summary, draft). The count of refused fields goes into `claims_dropped`.
2. **Window-bound citations.** `citedCallouts` takes `{ from, to }`. A cited callout counts only when `from <= seen_at <= to` and `to <= now`. The feed window is `window_min` before the run's `as_of`; the coin window is the coin's in-play window. A borrowed id is dropped and counted.
3. **Markers are a field.** Engine output carries `cites: string[]` beside the text; core never parses ids out of prose. Remove any core code that does.
