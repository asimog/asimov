# D5: An escalation denied by quota still runs in a later slot

Mode: B (the Slow Bridge) · Writer: top agent · Depends on: D1 (the grants it reads) · PLAN row: D5

## Current behavior
- observed: one tick does `schedule()` then `drain()` (`services/slow-bridge/src/main.ts:36-47`). A long drain (a run of up to `SLOW_RUN_TIMEOUT_S`, 1800 s) delays reading escalations, so escalations are not on their own timer.
- observed: when the per-hour quota is spent, the escalation is skipped and the cursor still advances past it (`services/slow-bridge/src/bridge.ts:63-69`), so the escalation is dropped, not deferred.
- observed: the mapper writes a swarm result with any number of actions (`services/slow-bridge/src/mapper.ts:31`); a zero-action swarm counts as success.
- observed: MiroShark's `wave_p` averages every sample, truncated ones included (`services/miroshark/engine/backend/asimog_worker.py:356-360`).
- suspected: "real round numbers": forum line `round` is the array index (`mapper.ts:30`), not the engine's round. Check what BettaFish returns.

## Required behavior
1. **Two timers.** The Bridge reads escalations every `SLOW_SCHEDULE_S` (default 5 s), whether or not a drain is running. Runs drain on their own loop. One `busy` flag per loop, not one shared flag.
2. **Deferred, not dropped.** A grant denied by quota or caps goes to `slow.jobs` with state `deferred` and the reason. Each schedule tick moves the oldest deferred jobs to `queued` while quota allows, oldest first. A deferred job older than `SLOW_DEFER_MAX_MIN` expires as `failed: expired` (a coin run an hour late is worthless).
3. **Empty swarms fail.** A swarm with zero simulated actions is finished `failed: empty_swarm` and writes no `swarm.wave_p`.
4. **Truncated samples are excluded from means.** `wave_p`, `d_callers` and `d_net_sol` average only full samples; `samples` counts those; `truncated` is true when any were cut.
5. **Real round numbers.** Forum lines carry the engine's own round.

## Invariants
The Bridge owns no business rule: the gate's choice comes from core (D1). Jobs stay idempotent by (engine, kind, subject, slot). Restart-safe: a deferred job survives a restart.
