3. **Duplicates and concurrency.** A known `job_id` returns its existing run (409 or the same `run_id`) and never starts a second one. More than `*_MAX_CONCURRENT` running jobs gets 429.
4. **Cancel.** `DELETE /asimog/runs/<id>` stops the run at its next model call and marks it `failed: cancelled`.
5. **Required env per engine.** Each worker refuses to boot, naming each missing key; MiroShark gets the same `check_env`.
6. **Prompt fencing.** Callout text, coin names and report texts from the other engine go into prompts inside the same `<<<...>>>` fence core uses (`services/core/src/reflex/guard.ts`: hidden characters removed, NFKC, fence marks stripped), with a line telling the model the fenced text is data.
